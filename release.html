Chapter 2What shipped

  • Eidolon as a router skill with three modes: setup, build and autopilot.
  • The native persona pipeline: agent files generated from the persona roster with tools, model and effort; a write lane per worker; the brief gate; the dispatch log; SubagentStart and SubagentStop hooks; a wave plan before any swarm; and a causal reasoning rail in every persona.
  • The autopilot guide for loops, goals and routines, opening with a brain dump and a chips interview.
  • The engineering principles reference.
  • A drift test that checks the hooks README against the code.
  • A hardened installer: preview by default, apply bound to the digest of the previewed plan, a vendor lock, staged writes with rollback, and backups with receipts.
  • Setup, which opens a session with the brain dump and asks only for what is missing.
  • Hearth with two doors: a novice door with no Node and no hooks, and an operator door that needs Node 22 and wires the project hooks.

Chapter 3What was fixed

The PowerShell tool now reaches the shell guards. The release also fixes these shapes: combined short flags such as -nm, a hooks path set through GIT_CONFIG_*, cd followed by a relative path, redirect and copy overwrites of records, and path spellings that got past the record guards. The drift counter is now wired after each write, and the dispatch matcher is Agent.

Chapter 4What was removed

  • From Eidolon: the Codex adapter and the text written for two hosts; the vendored ASI-Evolve engine and evolve mode; the security-attestation and review-receipt ceremonies; the September persona-pipeline command line tools; and the advisor, conduct, process-doctrine, security-surface and orient-gate hooks.
  • From Hearth: the three graphical installers (the Windows WPF window, the macOS app and the browser installer), Codex support, the optional tool cards, and AGENTS.md.

For Hearth, Git history keeps what was removed.

Chapter 7Live gates

G2 to G4 ran in headless Claude Code 2.1.206, in a throwaway project after a real install, with hook debug logging on. G1 and G5 were settled later the same day in sandboxes.

G1, the novice door
With the user folder redirected to an empty one, 159 of 159 skill files landed byte for byte and nothing else was written. A fresh session listed both skills. An old June copy in the user folder loaded ahead of the project copy, so it was archived and the platform notes now say to keep one copy per machine.
G2, the guards
git commit -n was blocked. Deleting a hook through the PowerShell tool was blocked, which shows the shell guard reaches PowerShell. A dispatch with no Done-check: line was refused. git push --force-with-lease passed the hook; Claude Code's own permission layer then denied the push, which is separate from Eidolon.
G3, a dry run
/eidolon --dry-run produced the recon and the ten-stage plan and wrote nothing. It passed on the second attempt.
G4, the pipeline
A wave plan was written, then a builder agent ran on haiku with the lane src/**. Its writes outside the lane were blocked, the dispatch log recorded it, and a worker that tried to dispatch was blocked. Setting the spawn depth to 1 did not remove a worker's Agent tool, so the dispatch guard is the control that stops recursion.
G5, the interview
The brain dump, the reflect-back and the goal text all worked, and the goal reached its end state. The interview guessed the permission choice instead of asking, and the guide now forbids that.
The macOS doors
Ran on GitHub's macOS runner and under WSL Ubuntu.

Chapter 8Still open

  • Claude Code's built-in /goal evaluator in an interactive session. Headless mode does not expand slash commands, so this needs a person.
  • A run of the doors on a user's own Mac.
  • Whether Claude Code itself refuses a worker's spawn at depth 1. The dispatch guard blocks the call first, so this has not been seen.
  • Whether the installer's Node 22 check runs before any syntax an older Node would reject. Running it under Node 20 would settle this.

The hooks remain defense in depth. Their known gaps are the honest limit of what they cover.

Chapter 9How this release came about

An audit on 13 October 2026 found four lines of this harness that had drifted apart. GitHub main, dated 10 September, was the only one with CI, pins and public history. The other three held months of work that had been verified green in a working tree but never committed or pushed:

  • a triage refactor from 9 July and a skill cleanup from 5 September, in a local clone;
  • a re-mirror of Hearth from 9 July;
  • a "safety program" in Codex worktrees from 13 September, verified through builds 1 to 4 and 7, and stopped at build 5 of 14.

Two separate measures agreed that the hooks were lexical and could be bypassed, while the docs called them hard enforcement.

The owner's decisions that day made GitHub main canonical, with one reviewed re-cut on top of it. The three uncommitted lines are kept as archive branches and never merged.

The intent behind the old persona tools was rebuilt on Claude Code's own agents, hooks and settings. The docs now call the hooks defense in depth, and a drift test holds every documented block and ask to the code. The graphical installers had measured contrast ratios of 4.02, 3.42 and 2.89 to 1 against a 4.5 target; those numbers are kept in the record, and the installers are gone.

The full account is the decision record, 2026-10-13-archive-branches-and-v010-re-cut.md.
