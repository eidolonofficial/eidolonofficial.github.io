Standing on

The open source this runs on

Eidolon stands on work by other people. The credits files in the repositories name each project with its author, its license and its link. This page repeats the short form. Thank you to all of them.

  • Addy Osmani

    agent-skills (MIT) is the lifecycle harness this pattern grows from. Its reviewer, test-engineer and security-auditor roles shaped the swarms. The toolkit also uses web-quality-skills (MIT), agent-engineer (Apache-2.0) and learning-jsdp (MIT). It also uses critical, squish, timing.js, tmi, puppeteer-webperf and a fork of loadCSS. Eidolon reads essential-js-design-patterns (CC BY-NC-ND) and never adapts it.

  • codebase-memory-mcp

    The local code graph Eidolon asks first for structure questions. MIT. By DeusData.

  • graphify

    The graph of docs, schemas and code that Eidolon reads as its fallback. Apache-2.0 and MIT. Led by safishamsi.

  • mempalace

    The written memory store Eidolon wires when it is present. MIT. Led by igorls, with 79 contributors.

  • trust-but-verify

    His own audit skill. MIT. Its root-cause frameworks give the house persona its method for hard problems. They are 5 Whys, Fishbone, Fault Tree, Bow-Tie, Kepner-Tregoe, Pareto and DMAIC.

  • ponytail and caveman

    The two plugins behind the token economy. The ponytail plugin (MIT, by Dietrich Gebert) is the ladder that stops at the first rung that works. The caveman plugin (Apache-2.0, by Julius Brussee) is the short register for chat and reports. Its cavecrew presets do cheap scouting and small edits.

  • rtk, headroom, repomix and LLMLingua

    The compressors Eidolon offers and never bundles. The rtk tool (Apache-2.0 CLI) shortens command output. The headroom tool (Apache-2.0) shrinks tool results and keeps the originals to hand. The repomix tool (MIT) packs a repo into one file. LLMLingua (MIT) compresses long prompts with a small local model. Compressed output is never evidence.

  • quicklink

    Part of the web-performance toolkit. Apache-2.0, by GoogleChromeLabs.

  • Python, uv, Chroma, transformers and NumPy

    The foundations under the memory tools. Each has its own contributors file.

  • OWASP, MITRE ATT&CK and CWE, NIST SSDF, W3C WCAG 2.2 and WAI-ARIA

    The standards the review swarms check against.

  • Security tooling

    Semgrep (LGPL-2.1), Bandit, gosec, eslint-plugin-security and Brakeman for static analysis. gitleaks (MIT) and trufflehog (AGPL-3.0) for secrets. osv-scanner, Trivy and grype for dependencies. OWASP ZAP and nuclei (MIT) for dynamic checks. Checkov, syft and OpenSSF Scorecard for configuration and supply chain. Eidolon runs each one as its own program and links none of them in.
